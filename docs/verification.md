验证日期为 2026-11-23。全项目 319 项测试、Hydro 5.0.7 API 类型检查、Go 测试（含 Windows 目标的 `go vet`）、构建和 `pnpm test:ui`（103 个页面视图及座位与 IP、机位监控的操作）通过。
